# openplayer
Free and open-source music player for android with advanced functionality,

Features:
- Crossfade(0-15s) between tracks
- Playback is gapless
- On-device audio effects(speed/pitch/reverb/spatial audio)
- Next five songs can be rearranged or changed
- Clean UI, only what you need, nothing you don't
- Shuffle seed(save the combination that lines up all the best songs!)
- Notification shade media controls
- Ergonomic design
- Sleep timer
- Play from multiple playlists at once
- Background Playback
- Custom Background colors
- Less than 25mb filesize!
- Zero adds/paywalls
